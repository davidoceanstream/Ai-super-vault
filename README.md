## ⚡ 1-Click Quick Start & Installation

### Option A: Interactive 1-Click Menu (Human Friendly)
Double-click **`1_CLICK_INSTALL_MENU.bat`** in the repository root. A numbered console menu will guide you through installing presets or individual tools:
```text
[1] 💎 Core Sovereign AI Brain (ConverMem + ScmdSolution + Virtuoso)
[2] 🎬 Video, YouTube Creator & Creative Media Production
[3] 🧠 AI Memory, Knowledge Graph & Multi-Agent Swarm
[4] ⚙️ System Automation, Browser Agents & Desktop Tools
[5] 🔍 Reverse Engineering, Security Auditing & Quant Trading
[6] 📦 Install ALL 143 Tools
[7] 🎯 Custom Selection (Install Specific Tool by Number)
[8] 🛡️ Run Virtuoso Zero-Leak Privacy Audit
```

### Option B: Autonomous Agent CLI (Agent Friendly)
Autonomous agents can invoke `install_kit.py` with programmatic CLI arguments:
```bash
# Non-interactive preset installation
python install_kit.py --preset flagship --yes

# Dry-run inspection without cloning
python install_kit.py --preset video --dry-run

# Search catalog by keyword
python install_kit.py --search "reverse engineering"
```
